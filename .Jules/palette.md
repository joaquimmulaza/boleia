## 2026-09-10 - Missing ARIA labels in icon-only buttons\n**Learning:** The application uses `lucide-react` for icons. It is common for icon-only buttons (like the X close button) to lack `aria-label` attributes and proper `focus-visible` states, which makes them inaccessible for screen readers and keyboard users.\n**Action:** Whenever adding or modifying an icon-only button, always ensure it has an appropriate `aria-label` (in Portuguese, e.g., 'Fechar', 'Notificações') and includes `focus:outline-none focus-visible:ring-2 focus-visible:ring-primary dark:focus-visible:ring-offset-slate-900` for keyboard navigation focus.
